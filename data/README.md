# data/

Everything in this folder is generated by the pipeline and is ignored by git.

| Folder | Written by | Content |
|---|---|---|
| `interim/` | `bbp run ingest`, `bbp second-crop` | Source tables parsed into tidy Parquet, one file per source, plus the municipality label grid used for zonal statistics |
| `processed/` | `harmonise`, `area`, `reconcile`, `inventory` | Analysis tables |
| `release/` | `publish` | CSV + GeoPackage + `manifest.json` for a versioned data release (Zenodo/REDU) |
| `logs/` | every stage | Run logs and `checks_<stage>.json` (results of the invariant checks) |

Raw inputs are **not** copied here. Their location is set by `raw_root` in
`config/pipeline.yaml` (default: the folder that contains the repository), or
overridden in `config/paths.local.yaml`.
